# POINTERS Official Store
<!-- February151975@#$ -->

A React/Vite storefront for the MSU-Marawi College of Information & Computing Sciences POINTERS merchandise collection.

## Run locally

```sh
npm install
npm run dev
```

The storefront includes product filters, variant selection, a cart with a 5% CICS subsidy option, sizing information, and a checkout preview with a printable reference. Checkout is currently front-end only: it does not save orders or send student details to a database.

## Build

```sh
npm run build
```
